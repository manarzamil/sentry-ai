# Demonstration Media

This directory holds the short demonstration video and GIF of the helmet in operation.

**Status: not yet recorded.** No demonstration footage exists at the time of writing, and none has been fabricated.

Planned files:

- `sentry-ai-demo.gif` — 15-30 second loop embedded in the main README
- `sentry-ai-demo.mp4` — full-resolution source recording

Recording guidance:

1. Frame the helmet, the buzzer and the supervisor device showing the dashboard in a single shot so the cause and the effect are visible together.
2. Keep the clip between 15 and 30 seconds: idle state, triggered fall, audible alarm, dashboard alert, alert reset.
3. Record at 1080p, then export the GIF at roughly 800 px wide and under 10 MB so it loads on the README page.
4. If a GPS fix is available, hold the dashboard on screen long enough for the coordinates to be legible.

Files above 100 MB cannot be committed to Git and should be hosted externally with a link from the README.
